# The Agent speaks only through Actions

Everything people see in Discord is an Action the Agent chose: replying in the channel, starting a thread, reacting, showing the typing indicator, or doing nothing at all. The Bridge never posts or reacts on its own, and the Agent's final text is never shown. OpenCode's own Slack and GitHub integrations post the agent's final answer instead; we chose otherwise so the Agent can respond the way a member of the server would.
